### 一、今日要点

**[2] 同组用户读到凭据头**
📌 类型：AI自身安全

sdcb Chats 是一个汇集多家模型服务的大模型前端，并带有 MCP 服务器分配。公开问题单于 2026-11-21T21:42:55Z 指出，已被分配到某个 MCP 服务器的非管理员用户可以读取其他被分配用户的自定义请求头，其中可以包含发给下游 MCP 的 bearer 令牌。NVD 于 2026-11-23T18:17:13Z 公开 CVE-2026-135432，写明受影响范围为 1.10.0 起、低于 1.17.1；问题单核对的版本是 1.17.0.772。GitHub Advisory Database 把严重性标为 high，CVSS 3.1 基线分为 6.5，向量为 `CVSS:3.1/AV:N/AC:L/PR:L/UI:N/S:U/C:H/I:N/A:N`；项目于 2026-11-22T03:06:36Z 发布 1.17.1（标签 1.17.1.799），发行说明写明查看已分配用户详情改为要求管理员或该 MCP 的所有者，详情和管理列表不再向非所有者、非管理员返回服务器 URL 和请求头，问题单和发行说明都没有描述在野利用。

🔗 来源：[sdcb Chats 问题单 #148](https://github.com/sdcb/chats/issues/148) · [1.17.1 发行说明](https://github.com/sdcb/chats/releases/tag/1.17.1.799) · [NVD CVE-2026-135432](https://nvd.nist.gov/vuln/detail/CVE-2026-135432)

**[3] 助手会话缺少属主校验**
📌 类型：AI自身安全

Elastic 于 2026-11-23T20:43:34Z 和 2026-11-23T20:50:04Z 连续发布两则 Kibana Security AI Assistant 公告，问题类型都是缺少授权。CVE-2026-115291 影响 8.19.0 至 8.19.25 以及 9.1.0 至 9.5.6：持有 `elasticAssistant` 权限的用户可以删除同一空间内他人的会话，因为全部删除没有按属主过滤。CVE-2026-115296 只写明影响 9.2.0 至 9.5.6：对共享或全局会话的读取权限会被当成删除权限，私有会话不在这条路径上；两则 CVSS 3.1 都是 6.5，向量均为 `CVSS:3.1/AV:N/AC:L/PR:L/UI:N/S:U/C:N/I:H/A:N`。前一则的修复版本是 8.19.26 和 9.5.7，后一则的修复版本是 9.5.7。两则公告都没有写在野利用；暂时不能升级时，公告写明可从不可信角色移除助手权限，对后一个编号还可以停止共享，并把已有的共享或全局会话改回私有。

### 二、深度速览

#### 【AI 赋能防御】

本日没有带独立复测数据的新检测产品。可以落地的变化是 MONAI Label 终于有了高于 0.8.5 的发行版。0.8.6 的说明把两处写入问题都放进这个版本：数据存储上传的路径限制来自 10 月 19 日已合并的拉取请求 1915，会话上传的压缩包成员名和会话标识校验来自拉取请求 1942。说明同时写明，认证默认值 `MONAI_LABEL_AUTH_ENABLE=False` 不因版本变化而改变，任何能连上服务器的客户端在默认配置下都能到达这两个接口，因此不要把服务器暴露给不可信网络，只把角色授给可信用户，并以写入范围限于数据目录的无特权账户运行；若 0.8.5 或更早版本曾对不可信网络开放，要在重新投入使用前检查是否出现预期之外的文件改动。CISA 目录把勒索软件利用标为 Unknown，取证分诊标为 Yes，备注指向 GHSA-qc22-rmgc-vg94 和拉取请求 1915。

🔗 来源：[MONAI Label 0.8.6 发行说明](https://github.com/Project-MONAI/MONAILabel/releases/tag/0.8.6) · [CISA 已知被利用漏洞目录条目所依据的告警](https://www.cisa.gov/news-events/alerts/2026/11/23/cisa-adds-two-known-exploited-vulnerabilities-catalog)

#### 【AI 系统风险】

Kibana 的两则缺陷都要求调用者已经具备助手功能权限，区别在删除路径。全部删除走助手自己的内部 Elasticsearch 客户端，查询不带属主条件，所以同一空间里别人的会话也会被删掉。单条删除则把“能读到共享或全局会话”当成“可以删除”，被删的历史对原所有者不可恢复；公告写明私有会话到不了这条路径。9.x 公告列出的修复版本是 9.5.7，受影响区间一直写到 9.5.6，因此 9.2、9.3 和 9.4 线上落在区间内的版本，公告给出的去向也是 9.5.7。8.19 只出现在全部删除这一则里。

sdcb Chats 的缺口在 MCP 分配关系。问题单写明，返回已分配用户详情的接口沿用了“能看到这台服务器”的可见性条件，然后把每个被分配用户的自定义头一并选出；列出用户名的相邻接口反而限制为所有者或管理员。这些头是管理员为下游 MCP 配给该用户的凭据，应用会在该用户发起工具调用时带上。1.17.1 同时收紧了服务器 URL 和请求头在详情、管理列表和只读界面上的返回。NVD 的公开时间晚于问题单和发行版，版本区间以 NVD 描述为准，问题单只明确写了 1.17.0.772。

MONAI Label 0.8.6 没有改变默认不认证这一事实。目录中的“可能执行代码”是 CISA 对 CVE-2026-133968 的短描述；会话上传那一处只出现在发行说明里，说明没有给它 CVE 编号，也没有写它已被利用。
