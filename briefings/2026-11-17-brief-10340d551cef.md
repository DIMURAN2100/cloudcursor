### 二、深度速览

#### 【AI 赋能防御】

2.1.326 的变更写在编码代理自己的权限检查和沙箱里，发行说明没有给出拦截率。沙箱在 macOS、Linux 和 WSL 上收窄了默认可写的用户主目录，同时把会话 mods 目录中的编辑改为更频繁地询问，并减少沙箱命令可以写入的文件夹。登录材料被单独点名：文件工具拒绝写入 `.credentials.json` 一类签入文件，Bash 权限检查对更多会到达这些文件的命令先询问。bypass permissions 模式不再覆盖说明中点名的那一部分调用；PowerShell 工具在该模式下仍会询问更多命令，并拒绝其中一部分。插件加载的方向相反：展示字段格式错误不再使已启用插件停在拒绝状态，钩子和 MCP 服务器会随之加载，所以这一项要由部署插件的管理员核对，而不是由版本号本身保证。

🔗 来源：[Claude Code v2.1.326](https://github.com/anthropics/claude-code/releases/tag/v2.1.326)

#### 【AI 系统风险】

两份公告都要求行为者能够影响 MCP 客户端读到的内容，也都没有写在野利用。CVE-2026-126681 的后果是令牌离开服务器：连接配置不限制端点，上下文中的 InfluxDB URL 会成为令牌的目的地，令牌权限范围内的数据随后可以被访问。公告把行为者写成远程且未经认证，公布的 CVSS 3.1 向量则是本地、需要用户交互、无需权限。升级到 0.0.19 是公告写明的修复版本；在此之前，把令牌权限降到最小、并且不把服务器交给会处理不受信任内容的客户端，公告明确写成不能完全修复。用过受影响版本就要轮换令牌，轮换对象是曾经配置在该服务器上的 InfluxDB API 令牌。

CVE-2026-126816 的后果停在运行 MCP 服务器的那台机器上可以写到的文件，公告写明托管的 AWS 服务不受影响。只读标注使自动批准成为可能，因此路径检查若依赖用户在提示里亲眼看到 `output_file`，自动批准会把这一步跳过。1.0.31 把 `output_file` 解析并限制在基准目录内，目录由 `AWS_PRICING_MCP_OUTPUT_DIR` 配置，默认是服务器进程的工作目录；目录外的绝对路径、`..` 和逃逸出去的符号链接会被拒绝，`readOnlyHint` 改为 False。不能升级时，公告要求把 `generate_cost_report` 从自动批准配置中去掉。`awslabs.cost-analysis-mcp-server` 停在 1.0.5 及更低版本，公告写明不会再发布该包的修复版本。

🔗 来源：[AWS 公告 2026-185](https://aws.amazon.com/security/security-bulletins/2026-185-aws/) · [AWS 公告 2026-184](https://aws.amazon.com/security/security-bulletins/2026-184-aws/)

### 三、今日趋势洞察

MCP 服务器已经持有的令牌和文件权限，会跟着客户端上下文里新出现的地址或路径走。InfluxDB 服务器把配置好的 API 令牌发往提示注入放进上下文的 URL；定价服务器则因为只读标注，可能在无人确认输出路径时把报告写到预定目录之外。Claude Code 2.1.326 把同一类边界收回到代理进程内部：沙箱默认可写目录变窄，登录文件被文件工具拒绝写入，一部分 bypass permissions 模式下的调用重新进入询问或拒绝。工具标注和上下文中的地址，没有代替这些检查。

### 四、企业行动清单

- 盘点 `awslabs.timestream-for-influxdb-mcp-server`。版本处于 0.0.12（含）至 0.0.19（不含）的，按公告 2026-185-AWS 升级。公告写明 0.0.19 已处理 CVE-2026-126681，并建议升级到最新版本。PyPI 上 0.0.19 的上传时间为 2026-07-28T19:36:43Z，0.0.20 为 2026-08-05T12:25:13Z。用过受影响版本的，轮换为该服务器配置的 InfluxDB API 令牌。完成升级前，令牌只保留所需的最小权限，并且不要把该服务器交给会处理不受信任内容的 MCP 客户端。
- 盘点 `awslabs.aws-pricing-mcp-server` 是否低于 1.0.31，以及是否仍在使用 `awslabs.cost-analysis-mcp-server` 1.0.5 及更低版本。定价服务器升级到公告写明的 1.0.31 或更高版本。PyPI 上 1.0.31 的上传时间为 2026-06-09T13:45:51Z，1.0.32 为 2026-07-28T19:04:09Z。费用分析包按公告不会再发布修复版本，迁移到 `awslabs.aws-pricing-mcp-server` 1.0.31 或更高版本。不能升级时，从 MCP 客户端的自动批准配置中去掉 `generate_cost_report`。
- 升级定价服务器后，核对仍在使用的报告输出路径。公告写明 `output_file` 会被限制在基准目录内，该目录由 `AWS_PRICING_MCP_OUTPUT_DIR` 配置，默认是服务器进程的工作目录。越出该目录的绝对路径、`..` 和符号链接会被拒绝。
- 将 Claude Code 升级到 2.1.326。发行说明写明，沙箱命令在 macOS、Linux 和 WSL 上默认不再写入部分敏感主目录；仍需写入的目录，在用户设置或托管设置的 `sandbox.filesystem.allowWrite` 中允许。检查已启用插件：原先因 `plugin.json` 展示字段格式错误而未能加载的插件，现在会连同钩子和 MCP 服务器一起加载。
- 如拟申报黑龙江省模型服务机构库，核对《关于征集黑龙江省模型服务机构（第一批）的通知》全文中的适用主体和申报时限。通知写明的申报时限为 2026 年 11 月 16 日至 2026 年 11 月 27 日。
