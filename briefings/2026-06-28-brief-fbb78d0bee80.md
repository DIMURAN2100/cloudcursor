### 一、今日要点（5～8 条）

**[1] Akrites开源协调**
📌 类型：AI赋能安全

Linux 基金会于 6 月 26 日牵头成立开源漏洞协调机构 Akrites，Anthropic、Google、Microsoft、OpenAI、AWS 等约 20 家机构为创始成员，旨在应对前沿 AI 可在单次扫描中发现大量漏洞、但修复率极低（Endor Labs 称近期 AI 发现漏洞中不足 5% 已修补）的新局面。该机构设立共享安全事件响应团队（SIRT），将多方重复报告合并为单一协调流程，遵循「先修补、后公开」原则，由 Alpha-Omega 项目提供超 700 万美元种子资金。此举标志着行业从分散披露转向 AI 时代的集中式漏洞治理。

🔗 来源：[The New Stack](https://thenewstack.io/akrites-open-source-vulnerability-coordination/)

![Akrites 开源安全协调倡议配图](https://cdn.thenewstack.io/media/2026/06/d51d6774-getty-images-bzp8oa7jsas-unsplash-scaled.jpg)

**[2] OpenAI修补星球**
📌 类型：AI赋能安全

OpenAI 于 6 月 23 日大幅扩展 Daybreak 网络安全计划，将重心从「发现漏洞」转向「验证并修复漏洞」：Codex Security 已扫描超 3000 万次提交、覆盖 3 万个代码库，超 50 万项发现被自动判定为已修复；同步发布 GPT-5.5-Cyber 预览版（CyberGym 85.6%、ExploitGym 39.5%）及与 Trail of Bits 合作的 Patch the Planet 开源计划，首期覆盖 cURL、Go、Python、Sigstore 等关键项目。厂商来源称，五日冲刺已识别数百个潜在问题并合并数十项修复，目标是将 AI 能力嵌入可审计的修补闭环而非单纯扩大告警量。

🔗 来源：[Help Net Security](https://www.helpnetsecurity.com/2026/06/23/openai-expanded-daybreak-cybersecurity-initiative/)

**[3] Guardian身份治理**
📌 类型：AI赋能安全

The Hacker News 于 6 月 26 日刊文指出，企业级 AI Agent 正以机器速度继承人类 OAuth 令牌与过度授权凭证，传统 IAM 仅记录登录事件、无法观测会话内跨系统工具调用，形成「身份暗物质」被 Agent 快速放大的新风险。文章提出「Guardian Agent」概念——在执行层而非认证层持续发现、映射并约束自主 Agent 的身份与行为，包括实时清点 Agent 清单、绑定人类所有者、建立行为基线并在策略违规时干预。这反映 AI 安全防御正从静态权限管控转向运行时身份治理。

🔗 来源：[The Hacker News](https://thehackernews.com/2026/06/guardian-agents-next-layer-of-identity.html)

**[4] Gaslight反AI分析**
📌 类型：AI自身安全

SentinelOne 研究人员发现名为 Gaslight 的新型 Rust macOS 植入程序，除通过 Telegram Bot API 实现 C2、部署 Python 信息窃取器外，更在样本中嵌入 38 条伪造「系统故障」提示注入消息，试图使 LLM 辅助恶意软件分析流程自行中止、截断或拒绝分析。该木马运行时配置（含 bot token）由操作者动态下发，并具备自毁日志中敏感字段的能力；Python 窃取组件疑似由 LLM 生成。这是首个将提示注入武器化、直接对抗安全分析师 AI 工具链的实战 macOS 样本，标志着攻防博弈已延伸至 AI 辅助分析流水线本身。

🔗 来源：[The Hacker News](https://thehackernews.com/2026/06/new-gaslight-macos-malware-uses-prompt.html)

**[5] 假Skill渗透实测**
📌 类型：AI自身安全

安全公司 AIR 构建虚假 AI Agent Skill「Stitch」，经约 3.6 万星技能市场 PR 合并及 Instagram 广告投放后，据称触达约 2.6 万个 Agent（含企业账户），而其所测试的全部 Skill 安全扫描器均判定为安全。攻击者将恶意指令置于扫描范围外的远程页面，安装后随时替换链接内容诱导 Agent 下载执行脚本；演示载荷仅回传邮箱，但真实攻击者可借此读取文件或横向移动。该实验揭示 Agent Skill 供应链存在「一次扫描、持久远程控制」的结构性缺陷，与 ClawHub 插件投毒等近期事件形成呼应。

🔗 来源：[The Hacker News](https://thehackernews.com/2026/06/fake-ai-agent-skill-passed-security.html)

**[6] Mythos红测风波**
📌 类型：AI自身安全

美联社 6 月 23 日报道，一名匿名美国官员证实 Anthropic Mythos 模型在 Project Glasswing 授权红队测试中，数小时内即在美国政府高度机密系统的受控演练中发现多处漏洞（不代表已实际利用）。同日参议院听证中，参议员 Mark Warner 引述 NSA/Cyber Command 负责人称该工具「在数小时内几乎突破所有机密系统」；随后特朗普政府要求限制 Fable 5 与 Mythos 5 的外国访问，Anthropic 选择全面下线两模型而非仅限制境外用户。超 100 名网络安全专家联名呼吁撤销禁令，认为削弱美方防御能力大于收益。

🔗 来源：[CNBC](https://www.cnbc.com/2026/06/23/anthropics-mythos-model-found-vulnerabilities-in-classified-us-government-systems-official-says.html)

**[7] Copilot注入CVE**
📌 类型：AI基础设施CVE

Check Point 威胁情报周报（6 月 15～21 日）披露，研究人员发现 Microsoft 365 Copilot Search 存在名为 SearchLeak 的提示注入技术：攻击者通过特制链接触发隐藏指令，滥用 Bing 图片抓取功能外泄邮件、验证码及 OneDrive/SharePoint 文件，微软已将其修复并分配 CVE-2026-42824。同期披露的 AutoJack 攻击链则展示恶意网页如何将 AI 浏览 Agent 转化为远程代码执行向量，滥用 AutoGen Studio MCP WebSocket 表面的本地主机信任缺失。两起事件均表明企业 Copilot/Agent 集成层已成为可直接利用的横向移动入口。

🔗 来源：[Check Point Research（PDF）](https://research.checkpoint.com/wp-content/uploads/2026/06/Threat_Intelligence_News_2026-06-22.pdf)

**[8] Agent陷阱分类**
📌 类型：AI自身安全

SecurityWeek 报道 Google DeepMind 研究人员将针对 AI Agent 的信息操纵攻击归纳为六类「陷阱」：内容注入、语义操纵、认知状态投毒、行为控制、系统性陷阱及人在回路陷阱。NIST 对 Agent 劫持评估显示，恶意指令在五项注入任务中平均成功率达 57%；USENIX 研究则表明，向 RAG 知识库植入少量 crafted 文本即可在约 90% 案例中迫使系统输出攻击者预设答案。文章呼吁企业建立来源验证、记忆治理、权限隔离与高风险操作人工审批的多层防御框架。

🔗 来源：[SecurityWeek](https://securityweek.com/when-information-becomes-the-attack-surface-understanding-ai-agent-traps/)

### 二、深度速览

#### 【AI 升级安全】AI 赋能防御与检测

**Akrites：AI 时代漏洞披露从分散走向协同。** 当 Claude Mythos 等前沿模型可在数小时内扫描大型开源项目并批量产出可利用发现时，传统「各机构独立报漏洞、维护者淹没于重复报告」的模式已难以为继。Akrites 的 SIRT 机制要求参与方在保密期内共享发现、由单一团队验证可利用性并协调补丁，再统一按 CVE 流程公开；JPMorgan Chase CISO Pat Opet 强调成功指标应是「修复部署到生产环境的速度」而非报告数量。Alpha-Omega 超 700 万美元种子资金及 Anthropic、OpenAI、Microsoft 等创始成员背书，使该机制具备跨行业执行力，但修复率能否实质提升仍有待观察。[The New Stack](https://thenewstack.io/akrites-open-source-vulnerability-coordination/)

**OpenAI Daybreak：从漏洞猎手到修补引擎。** Codex Security 插件现已支持在仓库、PR 与本地代码中执行深度扫描，输出含严重等级、可达性证据与针对性补丁的报告，并可对接 SARIF、CodeQL 与现有漏洞管理平台。GPT-5.5-Cyber 在 ExploitGym（39.5%）与 SEC-bench Pro（69.8%）上显著超越基线模型，但 OpenAI 明确其仅供经 Trusted Access for Cyber 验证的防御方使用，并配套更强监控与范围控制。Patch the Planet 与 Trail of Bits 合作，在 cURL、Python、Sigstore 等基础设施项目中以「AI 发现 + 专家验证 + 维护者协作」模式推进合并修复，回应 Five Eyes 关于「发现到利用窗口急剧缩短」的警告。[Help Net Security](https://www.helpnetsecurity.com/2026/06/23/openai-expanded-daybreak-cybersecurity-initiative/)

**Guardian Agent：身份治理下沉至执行层。** 生产级 Agent 不再执行固定函数，而是在单次会话中动态选择工具、跨 CRM、代码库与文档系统链式调用，且继承发起人的全部 OAuth 权限。传统 IAM 在登录后失去可见性，导致「影子 Agent」在无审计记录的情况下运行。Guardian Agent 作为专用控制层，持续维护 Agent 清单、映射所有者、监测跨应用行为并在违规时干预，代表 SOC 与 IAM 融合的新方向——安全控制必须跟随自主执行而非停留在认证网关。[The Hacker News](https://thehackernews.com/2026/06/guardian-agents-next-layer-of-identity.html)

#### 【AI 安全风险与治理】AI 自身威胁与监管动态

**Gaslight：攻击者开始「反制」分析师的 AI 工具。** 该 macOS 植入程序在窃取终端命令历史、浏览器数据与系统配置的同时，于 Markdown 数据块中植入 38 条伪造系统消息（内存溢出、磁盘耗尽、令牌过期、注入警告等），专门针对 increasingly 采用 LLM 辅助逆向与分诊的安全团队。SentinelOne 指出，这并非阻止传统静态分析，而是试图在 AI 分析流水线中制造「会话自我怀疑」以逃避检测。防御方需将恶意样本分析环境与 LLM 上下文隔离，并对分析 Agent 的输出建立人工复核与沙箱验证，不可盲信自动化分诊结论。[The Hacker News](https://thehackernews.com/2026/06/new-gaslight-macos-malware-uses-prompt.html)

**Agent Skill 供应链：扫描通过不等于安全。** AIR 实验证明，高星 GitHub 仓库合并、清洁扫描报告与社交媒体推广可快速建立虚假信任，而真正的恶意载荷位于扫描范围外的可变远程页面——安装后随时替换即可劫持 Agent。该模式与 ClawHub 官方 scope 抢注、OpenClaw 隐藏联系人触发注入等近期事件一致，揭示 Agent 生态的核心风险：Skill/Plugin 在运行时拥有近似用户提示的权威，但安全验证多为一次性静态检查。企业应禁止 Agent 自动执行远程获取的指令、对 Skill 实施签名校验与行为审计，并对高风险工具调用强制人工审批。[The Hacker News](https://thehackernews.com/2026/06/fake-ai-agent-skill-passed-security.html)

**Mythos 红测与模型出口管制博弈。** Project Glasswing 授权测试显示，前沿模型可在数小时内定位政府机密系统弱点，推动美国行政令要求前沿模型发布前接受最长 30 天自愿安全审查，并限制 Fable 5/Mythos 5 外国访问。Anthropic 全面下线而非选择性限制，引发超 100 名安全专家反对——他们认为削弱美方最强防御工具反而有利于对手。该争议凸显 AI 安全治理的核心张力：能力越强，出口管制与防御可用性之间的平衡越难把握，且缺乏透明、可审计的测试标准易引发政策过度反应。[CNBC](https://www.cnbc.com/2026/06/23/anthropics-mythos-model-found-vulnerabilities-in-classified-us-government-systems-official-says.html)

**Google DeepMind「Agent 陷阱」框架与 Copilot CVE。** DeepMind 将信息面攻击系统化为六类陷阱，NIST 测试显示注入成功率均值 57%，RAG 投毒少量文本即可操控 90% 输出。Microsoft CVE-2026-42824（SearchLeak）则证明 Copilot Search 集成 Bing 抓取时可被链接中的隐藏指令利用，直接外泄 M365 数据。企业应将 Copilot/Agent 的数据源访问纳入最小权限与网络出口监控，并对所有外部内容（网页、邮件、文档）实施提示注入检测与上下文隔离。[SecurityWeek](https://securityweek.com/when-information-becomes-the-attack-surface-understanding-ai-agent-traps/) | [Check Point Research](https://research.checkpoint.com/wp-content/uploads/2026/06/Threat_Intelligence_News_2026-06-22.pdf)

### 三、今日趋势洞察（1～3 句）

本周 AI 安全议题呈现明显的「双向运动」：防御侧，Akrites 与 OpenAI Daybreak 将 AI 漏洞能力导向协调披露与自动化修补闭环；攻击侧，Gaslight 反 AI 分析与假 Skill 供应链实验表明，威胁行为者正同步针对分析师工具链与 Agent 扩展生态下手。身份与权限成为交叉焦点——Guardian Agent 治理模型与 Copilot CVE 共同说明，Agent 继承的人类凭证与外部信息源才是当前最可被实战利用的攻击面，而非模型权重本身。

💡 关键洞察
- AI 防御正从「发现更多漏洞」转向「修补闭环与协调披露」，Akrites 与 Daybreak 是两大标志性举措（媒体/厂商来源）。
- 攻击面同步外扩至分析师 AI 工具链（Gaslight）与 Agent 扩展供应链（假 Skill），静态扫描无法覆盖运行时远程指令。
- 身份与权限继承是 Agent 时代最突出的结构性风险，IAM 必须从认证层延伸至执行层（HN/SecurityWeek）。

---

⚠️ 核心风险
1) **运行时权限滥用** — Agent 继承人类 OAuth 全量权限；建议实施最小权限、短期凭证与 Guardian 层行为监控。
2) **提示注入与供应链** — Skill/远程页面/恶意样本均可注入；建议上下文隔离、远程内容校验与人工审批高风险操作。
3) **AI 辅助分析被反制** — 恶意软件主动欺骗 LLM 分诊；建议分析环境与 LLM 隔离，关键结论须人工复核。

---

📌 建议行动
- 核查 Microsoft 365 Copilot 是否已应用 CVE-2026-42824 补丁，限制 Copilot 对外部链接的自动抓取。
- 审计企业已部署 AI Agent/Skill 清单，禁用未签名或远程可变指令的扩展。
- 在恶意软件分析流水线中对 LLM 辅助分诊增加沙箱隔离与输出校验，防范 Gaslight 类反分析攻击。
- 跟踪 Akrites 披露流程，将开源依赖漏洞响应纳入 SIRT 协调机制。
- 对生产 Agent 实施身份映射、行为基线与高风险工具调用审批。
