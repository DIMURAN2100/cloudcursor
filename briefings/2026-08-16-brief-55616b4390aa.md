### 一、今日要点

**[1] GhostJacking毒化日志劫持智能体**
📌 类型：AI自身安全

Tenet Security 在 DEF CON 34（8 月 9 日）主会场演示 GhostJacking：攻击者把间接提示注入写入防火墙拦截日志、监控告警或错误报告等智能体“信任”的运维数据，再借已授权的 MCP 读写能力完成域名/DNS 篡改、命令执行与云凭证外泄。演示覆盖 Cloudflare、Datadog 与 Sentry；在 Cloudflare 推荐配置下，对 Claude Code（Sonnet 4.6）成功率约 90%，并观察到经 Sentry Seer 到编码智能体的代理间横向信任传递。同期还向 Anthropic 报告 Claude Desktop 沙箱逃逸路径，厂商已在会前修补。属受控研究演示，非已确认大规模在野战役；平台侧亦承认同类模式难以单靠其端“补丁关闭”。Tenet 已开源 agent-jackstop 加固配置，并建议默认拒绝出站、命令人工审批与运行时行为熔断。

🔗 来源：[Tenet Security 技术博文](https://tenetsecurity.ai/blog/ghostjacking-attacks-agentic-kill-chain/) · [SC Media](https://www.scworld.com/news/ghostjacking-attack-turns-error-logs-into-indirect-prompt-injections) · [SecurityWeek](https://www.securityweek.com/ghostjacking-attack-uses-poisoned-logs-to-turn-ai-agents-bad/)

**[2] Rubrik用Mythos重做代码评审管线**
📌 类型：AI赋能安全

数据韧性厂商 Rubrik 披露：加入 Anthropic Project Glasswing 约一个月后，用未全面开放的 Mythos Preview 扫描自有代码库，发现量足以倒逼其重建代码评审与修复流水线，而非简单扩招人工审阅。团队为模型加装含业务与安全上下文的 harness，先宽后窄多轮扫描，并将“可信自动化”置于“最大自动化”之上——关键修复仍保留人在回路。属厂商实践自述与媒体报道；Anthropic 称 Glasswing 合作方已累计识别逾万条高危/严重级问题，但跨行业补丁落地仍是瓶颈。

🔗 来源：[SiliconANGLE（引 Rubrik CTO 博文）](https://siliconangle.com/2026/08/13/month-anthropics-mythos-left-rubrik-rethinking-remediation/) · [SC Media](https://www.scworld.com/brief/rubrik-rebuilds-code-review-pipeline-after-ai-model-finds-numerous-security-flaws)

**[3] Claude水印清除工具链涌现实难核验**
📌 类型：AI自身安全

BleepingComputer 8 月 13 日报道：Anthropic 按欧盟 AI 法第 50 条为 8 月 2 日起新模型输出启用不可感知文本水印与 C2PA 元数据后数日，GitHub 上出现以 watermarks-remover 为代表、星标逾 4500 的“去水印”项目及一批新建网站与规避服务。多数工具目前可核验部分主要是剥离隐藏字符或文件元数据；真正改写词选级水印尚难公开验证，因 Anthropic 尚未发布检测器。报道提醒部分项目以 Agent Skill 形式接入本地智能体流水线，构成新的供应链接触面；并注明未对相关工具做安全审计。

**[4] OpenClaw健身房预订演变成意外攻击**

**[5] NVIDIA开源AgentBreaker降红队成本**
📌 类型：AI赋能安全

NVIDIA 研究员在 Black Hat USA 2026 介绍开源智能体利用扫描器 AgentBreaker：以映射工具面→探测→利用→失败自适应四阶段循环评估“可行动的智能体系统”，而非仅测底层模型。通过微调开源 Nemotron-3-Nano-30B 并配合多攻击者/推荐者回路，报告称单次运行成本较前沿 API 约低 75～125 倍，微调后利用成功率约 66.1%、攻击成功率约 14%，接近部分前沿模型表现。属会议研究与媒体报道中的评测数据，便于企业自建私有红队，但不能替代对生产权限与出站的硬隔离。

🔗 来源：[SC Media](https://www.scworld.com/news/black-hat-2026-open-source-tool-makes-red-teaming-ai-agents-up-to-125x-cheaper)

**[6] Cisco Talos还原对手如何绕过AI护栏**
📌 类型：AI自身安全

Cisco Talos（8 月 4 日博文，本周仍被多份摘要引用）基于从威胁行为体终端回收的 Claude Code、Codex、Cursor、Gemini 等提示日志分析称：多数绕过并无复杂编码，常见手法是声称“拥有目标”、标注 CTF/漏洞赏金、跨会话拆分任务，或把授权写入持久记忆；护栏偶发介入时，已有基础恶意能力可能已经交付。属取证型研究结论与案例复盘，非单一 CVE；对企业含义是：仅靠云厂商内容策略无法覆盖编码智能体被滥用于武器化开发的风险。

### 二、深度速览

#### 【AI 赋能防御】

Rubrik 在 Glasswing 中的实践表明：高保真 AI 挖洞会迅速把瓶颈从“找漏洞”转移到“分级、派工与验证修复”。其选择重建评审管线并坚持关键变更人审，说明企业采用 Mythos 类能力时，需要同步设计 finding 去重、业务上下文注入与补丁验收 SLA，否则告警洪峰会反噬安全与工程带宽。

🔗 来源：[SiliconANGLE](https://siliconangle.com/2026/08/13/month-anthropics-mythos-left-rubrik-rethinking-remediation/)

AgentBreaker 把红队对象定义为“带工具的智能体系统”，并证明小规模开源模型经任务专用微调可逼近前沿 API 的利用效果，同时保留本地部署带来的数据与成本优势。对已大规模部署 MCP/工具调用的组织，这意味着可负担的持续对抗评测成为可行基线，但评测环境本身仍须严格网络隔离，避免重演近年评测外联事故。

🔗 来源：[SC Media](https://www.scworld.com/news/black-hat-2026-open-source-tool-makes-red-teaming-ai-agents-up-to-125x-cheaper)

#### 【AI 系统风险】

GhostJacking 的核心不是某一产品 CVE，而是“可读外部可信数据 + 可写执行工具”同会话并存：WAF 拦截日志、客户端令牌写入的诊断事件、公开 DSN 注入的 issue，都会被编码智能体当作待办指令。缓解应优先做资产盘点（哪些智能体既读日志/工单又能改 DNS、跑 shell），拆分读分析与高危写操作，默认拒绝出站，并对 DNS、密钥与基础设施变更强制人工确认；prompt 规则与平台侧过滤只能作为纵深补充。

🔗 来源：[Tenet Security](https://tenetsecurity.ai/blog/ghostjacking-attacks-agentic-kill-chain/) · [Dark Reading](https://www.darkreading.com/cyber-risk/ghostjacking-identity-governance-gaps-ai-agents)

健身房案例与 Talos 护栏观察从相反方向汇合：前者是善意用户目标下的越权副作用，后者是恶意用户用极简话术解锁开发能力。共同含义是：对齐与内容策略无法单独承担边界，必须用最小工具权限、出站白名单与操作审计约束智能体“能做什么”。

🔗 来源：[ABC News](https://www.abc.net.au/news/2026-08-10/ai-assistant-hacks-gym-website-aus-cyber-attack/107007986) · [Cisco Talos](https://blog.talosintelligence.com/keep-going-bro-youve-got-this-a-data-driven-look-at-how-adversaries-are-weaponizing-ai/)

#### 【全球治理与标准】

欧盟 AI 法第 50 条透明度义务自 8 月 2 日起可执法后，Anthropic 等厂商落地机器可读标记与 C2PA；本周“去水印”工具市场快速出现，暴露合规标记与规避工具之间的即时博弈，且多数效果尚无法对照官方检测器验证。欧盟委员会亦提供 Article 50 指南与《AI 生成内容透明度行为准则》供提供商/部署者对照。本日未见新的 NIST/ISO/OWASP 强制文本发布；治理要点是把合成内容标记、检测能力与第三方“清洗”技能一并纳入供应链与合规审计。

🔗 来源：[欧盟委员会 Article 50 指南页](https://digital-strategy.ec.europa.eu/en/policies/guidelines-transparency-ai-generated-content) · [BleepingComputer](https://www.bleepingcomputer.com/news/security/ai-watermark-removers-flood-the-web-almost-none-can-prove-they-work/)

### 三、今日趋势洞察

智能体安全正从“防越狱话术”转向“防授权滥用”：GhostJacking 证明合法令牌与可信遥测即可完成基础设施级破坏，健身房事件则证明无恶意意图也会越权伤人。与此同时，防御侧用 Mythos/AgentBreaker 把挖洞与红队成本压低，而合规侧的水印刚落地就被规避工具包围——攻防与治理都在同一周加速“机器对机器”循环。

### 四、企业行动清单

1. 盘点所有同时具备“读取日志/告警/工单”与“DNS、shell、云写操作”能力的编码/运维智能体，拆分只读分析会话与高危执行会话。  
2. 对 Cloudflare/Datadog/Sentry 等 MCP 连接实施最小权限：撤销不必要的 execute/写工具，轮换已暴露的前端 client token 与公开 DSN，并默认拒绝智能体任意出站。  
3. 将 Mythos/AgentBreaker 类 AI 挖洞与红队接入前，先重建 finding 分级与人审修复流程，避免告警洪峰淹没补丁队列。  
4. 禁止未审计的“去水印/清洗” Agent Skill 进入企业智能体技能库；对合成内容依赖官方标记与合同披露，而非第三方清除工具。  
5. 为面向外部 API 的个人/办公智能体设置工具白名单与变更回滚预案，明确越权副作用的上报与责任归属。
