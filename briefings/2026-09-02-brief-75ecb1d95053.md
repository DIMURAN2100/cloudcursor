全球网络安全简报（AI 专题）— 2026-09-02（GMT+8）

本期资讯以过去约 24～48 小时（约 2026-08-31 至 09-02）公开可核验来源为主；NVIDIA NemoClaw / OpenShell 安全公告首发于 8 月 25 日，因 NVD 于 9 月 1 日更新 CVE-2026-65105 记录且研究方与权威媒体仍在跟进，作为直接影响 AI Agent 推理链路的重大基础设施风险新进展收录。

### 一、今日要点

**[1] 欧委会将 ChatGPT 纳入 DSA 超大型搜索引擎**
📌 类型：AI治理合规

欧盟委员会宣布将 ChatGPT 指定为《数字服务法》（DSA）下的超大型在线搜索引擎（VLOSE），同时将 Reddit、Roblox 指定为超大型在线平台（VLOP）。欧委会认定 ChatGPT 可响应用户提示并检索网页，构成混合型搜索服务；被指定服务须在四个月内（至 2027 年 1 月）履行系统性风险评估、缓解措施、独立审计等额外义务。该决定使 DSA 超大型名单增至 28 项服务，欧委会将与爱尔兰等数字服务协调机构联合监管。新闻稿页面标注于 2026-09-01 更新。

🔗 来源：[European Commission](https://ec.europa.eu/commission/presscorner/detail/en/ip_26_1772) · [iThome](https://www.ithome.com.tw/news/178567)

**[2] 假冒 Claude Opus 5 桌面版投递 RevStealer**
📌 类型：AI自身安全

Morphisec 披露，攻击者在 GitHub 上以仿冒 Anthropic 的 “Claude Opus 5 Free Desktop” 仓库为诱饵，分发约 101 MB 的伪装 Electron 桌面应用，实际投放 Windows 信息窃取木马 RevStealer。样本会做沙箱与区域语言检测、尝试将 AppData 加入 Defender 排除项，并以间接系统调用、加密配置及 Polygon 链上智能合约回退 C2 等方式降低可见度；窃取目标涵盖浏览器凭据、密码管理器与加密货币钱包数据后自删。Help Net Security 于 9 月 1 日跟进报道。属已确认的社工投递与恶意样本分析，并非模型本身被越狱。

🔗 来源：[Morphisec](https://www.morphisec.com/blog/revstealer-silence-is-its-greatest-weapon/) · [Help Net Security](https://www.helpnetsecurity.com/2026/09/01/revstealer-malware-claude-opus-5-github/)

**[3] CrowdStrike 发布 Falcon Guardian 智能体运行时防护**
📌 类型：AI赋能安全

CrowdStrike 于 9 月 1 日宣布推出 Falcon Guardian（厂商来源），将其定位为 AI Detection and Response（AIDR）旗舰能力：在受支持的 Windows / macOS / Linux 端点发现影子 AI Agent，并将提示、技能、工具调用、MCP 服务器与身份同端点遥测关联，形成“提示到运行时行为”的因果链。产品宣称可对受支持 Agent 类型做准入治理，并延续对提示注入与敏感数据暴露等场景的防护；还将引入 AI 网关，并把跨域狩猎与 MDR 扩展到 Agent 场景。以上为厂商产品发布与能力表述，尚非独立实测结论。

🔗 来源：[CrowdStrike](https://www.crowdstrike.com/en-us/blog/falcon-guardian-defines-next-generation-of-ai-security)

**[4] 美军 GenAI.mil 上线 ChatGPT Mil 与 Grok for Government**
📌 类型：AI治理合规

美国战争部（Department of War）发布新闻稿，宣布在 GenAI.mil 平台部署 OpenAI 的 ChatGPT Mil，面向非密业务；OpenAI 同步说明该定制版本运行于经授权的政府云，内建安全控制，且平台数据不用于训练其公开或商业模型。同日相关发布亦覆盖 Starshield AI 的 Grok for Government。官方称 GenAI.mil 上线逾九个月已吸引超过 170 万不重复用户。此为政府侧 AI 部署与数据隔离承诺的公开确认，不等于对模型安全边界的完整评测结果。

🔗 来源：[U.S. Department of War](https://www.war.gov/News/Releases/Release/Article/4586352/department-of-war-launches-openais-chatgpt-mil-on-genaimil/) · [OpenAI](https://openai.com/index/bringing-chatgpt-to-genaimil/)

**[5] NemoClaw 未鉴权推理接口可致本地模型持久投毒**
📌 类型：AI基础设施CVE

NVIDIA 安全公告（2026 年 8 月）披露 NemoClaw for Linux 的 CVE-2026-65105（CVSS 8.1，高危，CWE-306）：推理服务配置不当可使相邻网络攻击者在无鉴权情况下访问本地推理接口，可能导致信息泄露与拒绝服务；受影响版本为 0 至 0.0.25。Cyera / Oasis 研究演示称，NemoClaw 将 Ollama 绑定至 `0.0.0.0:11434` 并结合 DNS 重绑定后，可改写模型聊天模板，使隐藏指令在后续对话中持续生效（研究演示，非在野大规模利用确认）。同公告还包含 OpenShell 多项高危 / 严重漏洞。NVD 记录显示该 CVE 于 9 月 1 日仍有更新；官方建议从 NVIDIA/NemoClaw 与 OpenShell 仓库获取修复版本。

🔗 来源：[NVIDIA Product Security 5872](https://github.com/NVIDIA/product-security/tree/main/2026/5872) · [NVD CVE-2026-65105](https://nvd.nist.gov/vuln/detail/CVE-2026-65105) · [Cyera Research](https://www.cyera.com/research/nemoclaw-one-website-visit-to-hijack-your-ai-agent)

**[6] Askeal 推出可核验来源的 AI 安全调查助手**
📌 类型：AI赋能安全

Help Net Security 9 月 1 日介绍初创公司 Askeal 的 AI 网络安全助手（厂商 / 媒体采访来源）：面向 SOC 与 IT 人员的自然语言调查，强调答案需附可核验来源，并在无相关情报时留空而非编造。产品能力覆盖 CVE 研判、URL / 域名 / 哈希核查与日志 IOC 提取等，并称结合人工审核贡献者与神经符号技术。当前仍处社区测试与能力建设阶段，宜视为 AI 赋能调查工作流的产品动向，而非已验证的 SOC 替代方案。

🔗 来源：[Help Net Security](https://www.helpnetsecurity.com/2026/09/01/askeal-ai-cybersecurity-assistant/)

### 二、深度速览

#### 【AI 赋能防御】

CrowdStrike Falcon Guardian 将防护重心从“模型交互内容检查”前推到 Agent 在端点上的真实执行：发现未批准 Agent、关联 MCP / 工具调用与系统行为，并把治理策略落到“允许哪些 Agent 类型运行”。其同时规划 AI 网关与托管狩猎 / MDR，反映厂商正把 EDR 范式迁移到 AIDR。上述均为厂商来源能力路线，企业评估时应要求厂商给出受支持 Agent 清单、误报处置与隔离边界。🔗 来源：[CrowdStrike](https://www.crowdstrike.com/en-us/blog/falcon-guardian-defines-next-generation-of-ai-security)

Askeal 则代表另一条路径：不主张用单一模型“自动关闭告警”，而是用 AI 聚合可核验情报，缩短人工调查取证时间。其明确反对在无证据时硬凑结论，对缓解大模型幻觉进入安全处置链路有参考价值。🔗 来源：[Help Net Security](https://www.helpnetsecurity.com/2026/09/01/askeal-ai-cybersecurity-assistant/)

#### 【AI 系统风险】

NVIDIA NemoClaw / OpenShell 公告显示，Agent 安全失败点常在“沙箱旁路与本地推理管线”，而非模型权重本身。CVE-2026-65105 的关键机制是本地推理 API 无鉴权暴露；研究侧进一步指出模板投毒可在 Agent 自带系统提示之后仍注入持久指令，使后续编码、包推荐或数据外传被静默操纵。同批 OpenShell 漏洞包含沙箱逃逸与命令注入等严重项，说明 Agent 运行时组件需按生产基础设施同等补丁纪律管理。当前公开材料以厂商公告与负责任披露研究为主，CISA SSVC 对该 CVE 标注 exploitation 为 none。🔗 来源：[NVIDIA 5872](https://github.com/NVIDIA/product-security/tree/main/2026/5872) · [Cyera](https://www.cyera.com/research/nemoclaw-one-website-visit-to-hijack-your-ai-agent)

假冒前沿模型桌面客户端的 RevStealer 活动表明，AI 品牌与“免费高阶模型”叙事已成为高转化社工面。防御重点在软件获取渠道、代码签名与下载信誉，而非提示词过滤。🔗 来源：[Morphisec](https://www.morphisec.com/blog/revstealer-silence-is-its-greatest-weapon/)

#### 【全球治理与标准】

欧委会将 ChatGPT 指定为 DSA VLOSE，把通用对话式 AI 明确纳入超大型搜索引擎监管框架，强制系统性风险治理与透明度义务，标志着“AI 产品形态”开始被既有数字平台法直接捕获。美军 GenAI.mil 同步扩大多模型供给并强调政府云隔离与不用于外部训练，体现高敏感场景下的部署治理并行推进。🔗 来源：[European Commission](https://ec.europa.eu/commission/presscorner/detail/en/ip_26_1772) · [Department of War](https://www.war.gov/News/Releases/Release/Article/4586352/department-of-war-launches-openais-chatgpt-mil-on-genaimil/)

### 三、今日趋势洞察

通用大模型正同时被“平台级监管”与“政府专网部署”两端塑形：一端用 DSA 超大型义务约束面向公众的系统性风险，一端用隔离云与数据用途限制承接高敏任务。与此并行，攻击与防护都在离开纯提示层——一边是本地推理 / 沙箱管线配置失误导致的持久模型投毒，一边是端点运行时把 Agent 工具调用与系统行为串联取证；AI 品牌本身亦成为供应链社工的高效入口。

### 四、企业行动清单

- 盘点开发者工作站与实验室中的 NemoClaw / OpenShell / Ollama 部署，确认版本已离开 0–0.0.25 受影响区间，并禁止将本地推理 API 绑定到非回环地址。
- 将“未签名 / 仿冒厂商的 AI 桌面客户端与 GitHub 免费模型仓库”纳入软件下载与终端防护策略，阻断 Electron 加载器类诱饵。
- 建立企业批准的 AI Agent / MCP 服务器清单，禁止未登记 Agent 在托管端点常驻运行，并记录工具调用与身份映射。
- 法务与合规对照 DSA VLOSE/VLOP 义务，评估面向欧盟用户的对话式检索类 AI 服务是否触发系统性风险评估与审计准备。
- 对接入政务或国防类专网的生成式 AI，核验数据驻留、训练用途隔离与提示/输出审计是否写入合同与技术控制。
