### 一、今日要点

**[1] Cursor恶意Claude扩展**
📌 类型：AI基础设施CVE

Cursor 于 10 月 29 日发布安全通告：当日约太平洋时间 02:27–13:35，Cursor VS Code 扩展市场短暂分发冒用 Anthropic 标识的 `Anthropic.claude-code` 2.1.312 / 2.1.313（Windows/macOS），该包并非 Anthropic 开发。扩展在模块加载时执行注入的 JavaScript：采集主机与用户信息、向 `authorized_keys` 追加攻击者 SSH 公钥、尝试启用本地 SSH 并建立反向隧道，以及写入 LaunchAgent / 计划任务等持久化；Cursor 估计最多约 5,000 名用户受影响，并称因恶意代码错误与权限限制，多数主机上 SSH 启用步骤会失败，但密钥写入、持久化与主机信息外传仍可能发生。Cursor 已下架恶意版本、短暂停市并轮换密钥重建市场，配合云厂商下线攻击者服务器；Microsoft Threat Intelligence 10 月 30–31 日分析确认 Visual Studio Marketplace 与 npm `@anthropic-ai/claude-code` 未受影响，Anthropic 亦向微软确认自身系统未遭入侵。属已确认的 AI 开发者工具供应链投毒，卸载扩展本身不足以清除独立持久化工件。

🔗 来源：[Cursor 安全通告](https://cursor.com/blog/claude-code-extension-security-notice) · [Microsoft Security Blog](https://www.microsoft.com/en-us/security/blog/2026/10/30/inside-malicious-claude-code-branded-cursor-extension-persistent-ssh-backdoor)

**[2] HF模型库挖矿后门活动**
📌 类型：AI基础设施CVE

Pluto Security 研究团队于 10 月 29 日发布「Load/Mine」报告：追踪到经 Hugging Face（及 ModelScope 镜像）模型仓库分发的挖矿与后门活动，涉及 7 个账户、31 个恶意仓库；活动及相关关联仓库下载量合计超过约 32,000 次（报告明确该数字为下载次数，非已确认感染或独立受害者）。载荷伪装为小型 Qwen2 测试检查点，依赖加载时启用 `trust_remote_code=True`，在权重落地前以调用方权限执行仓库 Python（经 `config.json` 的 `auto_map`）；目标侧重自托管推理环境（如 Xinference、GPUStack）及租用 GPU、共享笔记本与 CI。首波下架后数日内出现第二波，且扫描多聚焦权重格式与杀软签名，对建模 Python 行为覆盖不足。属研究机构确认的模型枢纽供应链活动与机制说明，不宜把下载量直接等同失陷主机数；缓解重点是否定未审代码的远程信任加载，并对已拉取仓库做落地审查。

🔗 来源：[Pluto：Load/Mine 报告](https://pluto.security/blog/hugging-face-malware-campaign-load-mine) · [Unite.AI 报道](https://www.unite.ai/pluto-security-details-load-mine-cryptomining-campaign-on-hugging-face)

**[3] Claude自主拼装跨平台利用链**
📌 类型：AI赋能安全

Anthropic Frontier Red Team 于 10 月 27 日发布研究：使用未公开发布的内部研究模型，在实验室条件下发现并拼接多条面向 Chrome、Safari、Android、Windows 与 Linux 的可工作利用链，涵盖一键/近零交互远程代码执行、同源策略绕过、锁屏设备数据窃取等；公司称均经协调披露，相关厂商已完成修补（例如向 Google 报告并获分配的多枚 Chrome CVE，以及 Linux 内核相关 CVE-2026-98432 等公开材料中提及的补丁路径）。Dark Reading、The Hacker News 于 10 月 28–29 日跟进，强调其为模型在受控提示下完成的研究演示与负责任披露，而非已观测到的在野攻击活动。属厂商来源的 AI 赋能漏洞研究能力展示，应与「已出现大规模自动化在野利用」严格区分。

🔗 来源：[Anthropic 研究原文](https://www.anthropic.com/research/discovering-vulnerabilities-with-claude) · [Dark Reading（10/29）](https://www.darkreading.com/application-security/claude-model-exploits-major-browsers-oses) · [The Hacker News（10/28）](https://thehackernews.com/2026/10/anthropics-unreleased-ai-model-chains.html)

**[4] Prefab生成式UI沙箱逃逸**
📌 类型：AI基础设施CVE

NVD 于 11 月 1 日公开 CVE-2026-120338：`prefab-ui` 0.14.0 至 0.20.2 的 Generative UI 沙箱在 Deno 子进程中以 Pyodide 执行调用方（含 LLM）提供的 Python；启动时授予宽泛的 `--allow-read/write/net`，且运行时把 Deno API 留在 JavaScript 全局，经 Pyodide `js` 代理可调用 `Deno.readTextFileSync` / `writeTextFileSync`，从而以服务端 OS 用户读写文件，并可通过向虚拟环境 `site-packages` 写入 `.pth` 等方式持久化执行。常见远程路径为 FastMCP 的 GenerativeUI 提供方注册的 `generate_prefab_ui` 工具；无认证时可达客户端即可调用，有认证时则任意获准调用工具的客户端可触达。功能为可选且需安装 Deno。修复版本 0.21.0（提交 030f074 / PR #538）：在接受业务代码前撤销读写与网络权限并以 `--no-prompt` 阻止再授权。属确认的「LLM/MCP 生成代码沙箱权限过宽」缺陷与 CVE 编目；公开材料未声称在野利用。

🔗 来源：[NVD CVE-2026-120338](https://nvd.nist.gov/vuln/detail/CVE-2026-120338) · [修复提交 030f074](https://github.com/PrefectHQ/prefab/commit/030f074f85e0b1be0dd44b0283185aecb26337a2) · [v0.21.0 发布](https://github.com/PrefectHQ/prefab/releases/tag/v0.21.0)

**[5] Phorion解析扩展植入细节**
📌 类型：AI自身安全

安全厂商 Phorion 于约 10 月 30 日起公开对 Cursor 市场恶意 Claude Code 包的技术分析（Sophos X-Ops 等亦作摘要）：恶意逻辑为前置注入 `extension.js` 的约数十行加载器，在扩展宿主进程以当前用户权限于模块求值阶段执行，无需打开 Claude 对话。分析指出 macOS 上远程登录状态探测在非管理员权限下易误判，导致许多主机跳过 SSH 启用，从而削弱交互式后门成功率，但密钥追加、持久化脚本与明文 HTTP 信标仍构成凭据与主机画像风险。该材料属于对已确认供应链事件的独立技术复盘与狩猎要点补充，强化「仅按产品名清点不足、须核验市场来源与磁盘工件」的结论。

🔗 来源：[Phorion 安全公告](https://phorion.io/blog/offical-claude-code-vsx-compromise) · [Sophos 摘要](https://www.sophos.com/en-us/blog/malicious-claude-code-extension-distributed-through-cursor-marketplace)

### 二、深度速览

#### 【AI 赋能防御】

Anthropic 将未发布研究模型用于协调披露驱动的漏洞发现与利用链拼装，把「从单点缺陷到可验证 PoC」的人力门槛显著压低：Chrome 一例串联 V8 内存破坏、沙箱逃逸、CacheStorage 竞态与 FedCM UAF，Safari 一例则以数据面读写关闭同源策略而无需任意代码执行。对防御方，这意味着补丁优先级与浏览器/内核供应链响应窗口会被模型规模化研究进一步压缩；同时应把此类结果定性为受控研究能力，而非默认等同对手已掌握同等自动化火力。并行地，Microsoft 针对 Cursor 恶意扩展给出的攻击链复原与狩猎指引，把 IDE 扩展市场事件纳入与传统软件供应链同等的 EDR/网络检测闭环，是把 AI 编码助手安装面纳入日常检测工程的可操作做法。

🔗 来源：[Anthropic 研究原文](https://www.anthropic.com/research/discovering-vulnerabilities-with-claude) · [Microsoft Security Blog](https://www.microsoft.com/en-us/security/blog/2026/10/30/inside-malicious-claude-code-branded-cursor-extension-persistent-ssh-backdoor)

#### 【AI 系统风险】

本期风险集中在三类「信任代理」失效。一是 **编辑器扩展市场身份冒用**：恶意包复用官方扩展 ID，在加载瞬间获得与开发者同等的本机权限，提示注入防御与模型对齐对此路径无效。二是 **模型枢纽的远程代码信任开关**：`trust_remote_code=True` 把仓库 Python 变成安装程序，杀软与权重扫描无法替代对 `auto_map` 引用代码的人工/静态审查；下架后快速换号复现说明响应需含持续狩猎而非单次删除。三是 **生成式 UI / MCP 工具沙箱权限面过大**：Prefab 案例显示，即便使用 Pyodide/Wasm，若宿主 Deno 能力未在执行前收回，LLM 或未认证 MCP 客户端仍可落到宿主机文件读写与持久化。共性缓解：锁定扩展来源与哈希、默认禁止远程信任代码、对 MCP/生成代码路径实施最小权限与认证前置。

🔗 来源：[Cursor 安全通告](https://cursor.com/blog/claude-code-extension-security-notice) · [Pluto Load/Mine](https://pluto.security/blog/hugging-face-malware-campaign-load-mine) · [NVD CVE-2026-120338](https://nvd.nist.gov/vuln/detail/CVE-2026-120338)

### 三、今日趋势洞察

AI 软件供应链正在同时击穿「开发者端扩展市场」与「模型工件枢纽」两条高信任分发通道，攻击者优先复用官方标识与文档化远程执行开关，而不是先攻破模型权重；与之对照，前沿实验室已用研究模型把跨厂商利用链拼装压缩到可协调披露的节奏，使补丁窗口与企业检测工程都被迫按机器速度重排优先级。

### 四、企业行动清单

- 盘点在 10 月 29 日窗口内从 Cursor 市场安装或更新过 `Anthropic.claude-code` 2.1.312/2.1.313 的终端，按 Cursor 通告运行检查脚本，清查 SSH 公钥、LaunchAgent/计划任务与反向隧道进程，必要时重建主机并从干净环境轮换凭据。
- 审计 ML/推理流水线与 CI 中所有 `trust_remote_code=True` 及等价远程代码加载路径，对近 60 天内自 Hugging Face/ModelScope 拉取的小型「测试」检查点做 `auto_map` 与旁路 `.py` 审查，默认改为不信任远程代码。
- 将使用 Prefab Generative UI / FastMCP `generate_prefab_ui` 的服务升级至 `prefab-ui` 0.21.0+，关闭未认证 MCP 暴露，并验证沙箱进程不再保留可写 Deno 权限。
- 把 IDE 扩展安装来源、扩展 ID+版本哈希与模型仓库拉取事件纳入 EDR/软件资产检测规则，覆盖本次 Cursor 与 Load/Mine 公开 IoC。
- 对浏览器与内核安全团队建立「模型辅助漏洞研究加速披露」响应预案，优先跟踪 Chrome/Safari/Android/Windows/Linux 近两周高危补丁是否已全量覆盖生产基线。
