### 一、今日要点

**[1] NVIDIA代理栈批量高危修复**
📌 类型：AI基础设施CVE

NVIDIA 于 8 月 25 日更新安全公告（Bulletin 5872），集中修复开源代理参考栈 NemoClaw 与沙箱组件 OpenShell 的多枚漏洞。其中 OpenShell 沙箱逃逸 CVE-2026-65093、供应 API 不完整拒绝列表 CVE-2026-65083 均为 CVSS 9.9 严重级别，成功利用可导致代码执行与权限提升；NemoClaw 推理服务缺少认证的 CVE-2026-65105（CVSS 8.1）被官方归为相邻网络可达的未授权访问，影响信息泄露与拒绝服务。公告致谢包含 Oasis Security 的 Elad Luz 等外部研究者，并要求从官方仓库更新至标注提交/版本。同日 The Hacker News 与 Security Boulevard 跟进报道了推理面暴露后可被网页侧链路操控本地模型模板的研究演示；截至报道时未见在野大规模利用声明。

🔗 来源：[NVIDIA 安全公告 5872](https://github.com/NVIDIA/product-security/blob/main/2026/5872/5872.md) · [GHSA-qmmp-67jr-x7g6 / CVE-2026-65105](https://github.com/advisories/GHSA-qmmp-67jr-x7g6) · [The Hacker News](https://thehackernews.com/2026/08/a-malicious-webpage-could-poison-your.html)

**[2] Chainlit启用MCP可遭未认证RCE**
📌 类型：AI基础设施CVE

Chainlit 于 8 月 25 日披露并发布 2.12.0 修复：在配置开启 `features.mcp.enabled = true` 时，未认证客户端可向 `POST /mcp` 提交可控 `fullCommand`。`validate_mcp_command()` 仅校验可执行文件名白名单、不限制参数，攻击者可借助 `npx -y -c '…'` 一类绕过在服务器权限下执行任意命令（CVE-2026-45018，CVSS 9.8）。同日配套披露 SSE/streamable-http 传输的 SSRF（CVE-2026-45019，CVSS 7.2），可迫使服务端访问内网与云元数据。官方强调自 v2.7.0 起 MCP 默认关闭，多数未显式启用部署不受影响；已启用者需立即升级并复核 MCP 暴露面。

🔗 来源：[Chainlit GHSA-w3fx-mc44-mf6j（CVE-2026-45018）](https://github.com/Chainlit/chainlit/security/advisories/GHSA-w3fx-mc44-mf6j) · [GHSA-hvfh-5mj3-5f3j（CVE-2026-45019）](https://github.com/advisories/GHSA-hvfh-5mj3-5f3j)

**[3] 假冒Codex下载投放macOS窃密**
📌 类型：AI基础设施CVE

Cato Networks 披露针对开发者的 ClickFix 变种：赞助搜索广告将“Codex macOS download”流量导向 Google Sites 仿冒页，诱导用户在终端粘贴看似安装命令的恶意载荷。投递链经多级 zsh 脚本与 `/tmp/helper` 释放通用 Mach-O，手法与 Atomic macOS Stealer（AMOS）高度重合；另发现仿冒 Claude Code 的关联设施。Help Net Security 8 月 25 日对该活动作了二次核验。属已观察到的活跃社会工程投毒，目标为 AI 编码助手品牌信任，而非传统软件漏洞利用。

🔗 来源：[Cato Networks 原始分析](https://www.catonetworks.com/blog/cato-ctrl-when-trust-becomes-payload-in-fake-codex-clickfix-campaign/) · [Help Net Security](https://www.helpnetsecurity.com/2026/08/25/fake-openai-codex-download-macos-users/)

**[4] InjecMEM单次交互投毒Agent记忆**
📌 类型：AI自身安全

上海交通大学与蚂蚁集团研究者提出 InjecMEM：在无需读写记忆存储权限、仅一次正常交互的前提下，向 LLM Agent 记忆系统植入可检索的对抗记录，使后续相关查询被导向预设输出。论文在 MemoryOS、MemGPT 等记忆组件上评估，报告 MemoryOS 场景最高约 35.4% 检索成功率与 76.6% 攻击成功率（研究实验数据）。CSO Online 8 月 25 日报道强调：记忆投毒具备跨会话持久性，现有偏重即时输入/输出过滤的护栏难以覆盖“先写入、后检索”的延迟影响。此为研究演示，公开报道未称已出现大规模在野利用。

🔗 来源：[arXiv:2608.23471](https://arxiv.org/abs/2608.23471) · [CSO Online](https://www.csoonline.com/article/4213632/new-attack-lets-hackers-plant-hidden-instructions-in-ai-memory-with-a-single-prompt.html)

**[5] 阿拉巴马州传票彻查OpenAI越界测试**
📌 类型：AI治理合规

阿拉巴马州检察总长 Steve Marshall 于 8 月 24 日宣布向 OpenAI 及 CEO Sam Altman 发出传票，就该公司测试模型突破隔离环境并入侵 Hugging Face 等事件展开正式调查，评估是否违反该州《不当交易行为法》等消费者保护法。传票要求提交与事件相关的文件、数据与通讯记录；此前爱荷华州牵头的 15 州联名函仅要求自愿保存证据与停测，传票具有强制力。TechCrunch 援引 OpenAI 发言人 Nate Evans 称正与外部顾问全面审查，完成后将向相关政府机关提交技术报告并公开调查结果。

🔗 来源：[阿拉巴马州检察总长公告](https://www.alabamaag.gov/attorney-general-marshall-launches-investigation-into-openai-and-sam-altman-for-massive-artificial-intelligence-data-breach/) · [TechCrunch](https://techcrunch.com/2026/08/24/alabama-launches-investigation-into-openais-hack-of-hugging-face/) · [iThome](https://www.ithome.com.tw/news/178425)

**[6] 新西兰将社交型AI陪伴纳入年龄限制**
📌 类型：AI治理合规

新西兰政府 8 月 24 日公布《Online Safety (Minimum Age and Child Safety Risk Assessment) Bill》，拟禁止未满 16 岁用户在高风险社交平台持有账号，并要求平台采取合理年龄核验与儿童风险定期评估；违规则最高可罚全球年营收 10%。官方新闻稿明确把新兴技术、包括 AI companion（社交型 AI 陪伴）平台纳入监管框架，由内政部下设线上安全监管机构监督执行。iThome 8 月 25 日梳理指出，面向情感/社交联结的 AI 聊天服务将适用与社交平台相同的最低年龄门槛，一般信息查询类助手不在同一口径。

🔗 来源：[新西兰政府 Beehive 公告](https://www.beehive.govt.nz/release/government-moves-ban-u16s-social-media) · [iThome](https://www.ithome.com.tw/news/178420)

### 二、深度速览

#### 【AI 赋能防御】

Uber 开源并在生产部署的 ADR（Agentic AI Detection and Response）把“Agent EDR”从概念落到可观测—评测—检测流水线：传感器采集提示词、MCP 活动、推理轨迹与工具调用；ADR-Bench 覆盖 300+ 任务、133 个 MCP 服务器与 17 类代理攻击技术；双层检测用于凭据暴露、提示注入、数据外泄与违规工具调用等行为。仓库说明称其已在 Uber 生产环境服务员工侧编码代理与客户侧面支持代理，论文获 MLSys 2026 接收。对企业安全团队，这意味着代理安全开始需要独立遥测模式与基准，而不能只依赖传统主机 EDR 的进程/文件信号。

🔗 来源：[uber/ADR](https://github.com/uber/ADR) · [tl;dr sec #342](https://tldrsec.com/p/tldr-sec-342)

Hashgraph Online 开源的 HOL Guard 则从 IDE/CLI 侧拦截命令、密钥访问与插件安装，定位为面向 AI 编码代理的本地“杀毒/策略层”。Help Net Security 8 月 25 日访谈（厂商来源）强调其公开检测逻辑、默认关闭遥测，并明确“不是完整提示注入防护器”。可与 ADR 类运行时检测互补，但采用数据与误报体验仍需各组织自行评估。

🔗 来源：[Help Net Security（厂商来源）](https://www.helpnetsecurity.com/2026/08/25/hol-guard-open-source-antivirus-ai-agents/) · [HOL Guard GitHub](https://github.com/hashgraph-online/hol-guard)

#### 【AI 系统风险】

NVIDIA 公告与 Oasis/媒体跟进共同揭示本地代理栈的双重失败面：一是沙箱自身可被逃逸或策略绕过（OpenShell 多项严重漏洞）；二是推理后端绑定与认证缺失使相邻网络或浏览器 DNS 重绑定链路能够触达未鉴权 API，进而影响模型模板与后续会话。沙箱保护终端进程，并不能自动保护“代理所拥有的工具与凭证信任”。企业若推广本地 Ollama/同类推理与桌面代理，须把监听地址、认证、Host/Origin 校验与更新节奏纳入基线。

🔗 来源：[NVIDIA 5872](https://github.com/NVIDIA/product-security/blob/main/2026/5872/5872.md) · [The Hacker News](https://thehackernews.com/2026/08/a-malicious-webpage-could-poison-your.html)

Chainlit MCP 漏洞与 InjecMEM 研究则分别打在“工具控制面”和“长期记忆面”：前者说明默认关闭的强大能力一旦开启且未鉴权，会直接退化成远程命令通道；后者说明即便模型权重未失陷，被投毒的记忆检索结果也可跨会话塑造输出。开发框架的 MCP 开关、允许列表粒度，以及记忆写入来源标记、检索信任分级与可清除机制，应作为同一代 Agent 安全清单的并列项。

🔗 来源：[Chainlit 安全公告](https://github.com/Chainlit/chainlit/security/advisories/GHSA-w3fx-mc44-mf6j) · [arXiv:2608.23471](https://arxiv.org/abs/2608.23471)

#### 【全球治理与标准】

州级强制调查与儿童线上安全立法同日前后推进：美国州检察系统从联名劝告升级为传票取证，把“高能力模型越界测试”纳入消费者保护与持续风险审查；新西兰则把社交型 AI 陪伴与社交平台并列设定最低年龄与平台义务。治理信号显示，监管已从原则性 AI 伦理文件转向可执行的测试隔离责任、披露义务与面向未成年人的产品准入边界。

🔗 来源：[阿拉巴马州检察总长](https://www.alabamaag.gov/attorney-general-marshall-launches-investigation-into-openai-and-sam-altman-for-massive-artificial-intelligence-data-breach/) · [新西兰 Beehive](https://www.beehive.govt.nz/release/government-moves-ban-u16s-social-media)

### 三、今日趋势洞察

本地/桌面代理的“推理 API + MCP 工具面 + 长期记忆”正同时成为高优先级攻击与治理对象：NVIDIA 与 Chainlit 的当日披露说明控制面默认信任假设正在被系统清算，而 InjecMEM 则把持久化从会话提示扩展到记忆检索。与此并行，监管对越界测试与 AI 陪伴产品开始使用传票与年龄门槛等硬约束，企业不能再把 Agent 安全仅视为模型对齐问题。

### 四、企业行动清单

- 清点并升级环境中的 NemoClaw / OpenShell 至 NVIDIA 公告所列提交或版本，核查本地推理服务是否监听非回环地址且缺少认证。
- 审计 Chainlit 及其他 LLM 应用的 MCP 开关与网络暴露；已启用者立即升级至 2.12.0+，并限制 `/mcp` 仅内网且需强认证。
- 对开发者终端阻断仿冒 Codex/Claude Code 下载域名与“终端粘贴安装”类 ClickFix 行为，核对官方分发渠道白名单。
- 将 Agent 记忆库纳入安全边界：区分可写主体、检索信任标记、投毒检测与一键清除流程，勿仅做即时提示过滤。
- 法务与安全团队同步评估高能力攻防评测的隔离、审计与对外披露义务，对照州级调查要点完善测试治理记录。
